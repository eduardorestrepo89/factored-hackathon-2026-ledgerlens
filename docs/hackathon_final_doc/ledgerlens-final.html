The technical solution

One chat, one turn, end to end. Serverless, secure, in production on AWS.

  1. Sign in
  2. Session
  3. Every tool call is authorized
  4. The tools
  5. Honest about the mocks
The React chat signs the customer in with Amazon Cognito over OIDC (Authorization Code + PKCE). The token goes with every call to the agent's invocation entry point.
AgentCore Runtime validates the token and opens the session: short-term memory, context truncation (30-message sliding window, active) and compaction (summarization, built and switchable by config). Amazon Bedrock runs DeepSeek v3.2; Haiku 4.5 or Sonnet 4.5 swap in by config. Bedrock Guardrail screens input and output.
The agent takes the customer's Amazon Cognito token from the Identity token vault and presents it to the AgentCore Gateway (MCP). A Cedar policy approves the call only if the token carries a linked customer_id, the call is about that same customer and, to block a card or open a claim, the customer confirmed.
