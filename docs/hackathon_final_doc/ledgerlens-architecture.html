“Two tokens, and the model never touches either. The customer signs in with Cognito and PKCE; token one only says who they are, the sub, and the Runtime checks it. The agent trades that sub for token two, for the Gateway, and a Pre-Token Lambda stamps the customer id into it. Before any tool runs, a hook overwrites the id with token two's value, whatever the model wrote; then Cedar checks three rules, deny by default. Ask for another customer's cards: your own id goes out. Eval case E5b.”

“Evaluation decides what ships, and it reads the same spans. Ten frozen cases, normal to adversarial. A harness plays the customer against the deployed agent, three runs each. Code grades every session with 25 checks and four unsafe detectors, and AgentCore Evaluations gives a second opinion from the same spans. Baseline models were consistent on 4 of 10 cases. Haiku reached 8, and four probe prompts, forty cents, took it to 9; the tenth missed once in three runs. In production: 97% of runs pass, zero unsafe outcomes, under two cents per resolution. That's why we pay twice DeepSeek's cost: twice the reliability. One honest limit: the AWS judge can't parse Yes/No sessions, so our code has the final word.”
